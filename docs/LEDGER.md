# 生活账本
入口：后台“生活账本”。各渠道与发送者独立记账，管理员能查看全部账本。

微信文字或已有转写的语音，如“晚饭花了194”“工资到账八千”，通过已激活日常模型识别后直接入账，无需确认。清晰的多笔收支最多10笔，同时表达心情则一并记录；重复消息不会重复入账。
回复展示日期、金额、分类、账户。发现错误，可在后台删除并重新录入。后台删除为软删除，计入审计。
“查账”不调用模型，返回本人本月收支。旧“确认记账/取消记账”仅处理升级前草稿，旧草稿不阻塞新账目。

金额只支持人民币、最多两位小数，整数分存储。未提日期默认为北京时间今天；账户默认“默认账户”。模型结果仍须经过结构、金额、日期校验；失败不入账。
退款、转账、借贷、银行同步、余额对账及预算分配尚不支持。账户是名称标签，不是银行余额。
模型未配置/401/超时/格式错误时明确报不可用，不误发心理回复。语义含糊时才请补充完整信息。

历史数据不清理，新记录不再创建待确认草稿。发布与回滚见 PRD。
