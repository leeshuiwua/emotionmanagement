# 观心镜 PRD

版本：V1.1（微信个人号 MVP）  
状态：开发完成，待 Linux 真实账号联调  
更新时间：2026-08-30

## 1. 产品目标

观心镜让用户通过微信好友私聊随时记录情绪，并获得“共情—认知校准—MBTI 动态观察—传统文化观照—微行动”的结构化回复。系统管理员通过公网 HTTPS `3002` 管理后台添加微信个人号、扫码登录、配置模型 API 与查看运行状态。

## 2. 已确认约束

- 技术栈为 TypeScript、Fastify、React、SQLite。
- 单台 Linux 部署，不使用 Redis、消息队列或外部数据库。
- 管理后台默认中文，支持英文切换。
- 微信入口是个人账号扫码登录，不是公众号、企业微信或小程序。
- V1 使用 Wechaty Web Puppet；个人微信没有官方机器人 API，属于实验性接入。
- 登录会话只保存到服务器本地文件，不进入接口响应或日志。

## 3. 用户与价值

| 用户 | 目标 | 主要动作 |
| --- | --- | --- |
| 系统管理员 | 建立可用且可观察的微信入口 | 登录后台、添加渠道、扫码、启停、退出微信、配置模型 |
| 微信好友 | 在熟悉的私聊中记录当下 | 向已登录的个人微信号发送文本并接收回复 |

## 4. V1 范围

### 4.1 管理后台

- 管理员会话、CSRF 防护、审计日志。
- 添加“微信（个人号 · 扫码登录）”渠道并命名。
- 生成登录二维码，展示启动中、等待扫码、待手机确认、已登录、连接失败状态。
- 登录后显示微信昵称、会话本地保存说明、消息范围和最近连接时间。
- 启停消息处理；退出微信时删除对应本地登录凭据。
- 配置日常模型与安全复核模型的 Base URL、模型名和 API Key。

### 4.2 微信消息

- 仅处理好友文本私聊。
- 忽略群聊、自己发送的消息、图片、语音、视频及其他非文本消息。
- 按 `settingId + messageId` 幂等入库。
- 先运行安全分流，再生成常规五镜回复；高风险内容优先返回现实安全支持。
- 回复与原始文本存入本地 SQLite。

### 4.3 本地持久化

- 业务数据：`data/guanxinjing.db`，SQLite WAL。
- 微信登录会话：`data/wechat-sessions/*.memory-card.json`，目录权限 `0700`。
- 模型密钥：AES-256-GCM 加密后写入 SQLite。

## 5. 非目标

- 不读取历史聊天记录、朋友圈、群聊或通讯录进行画像。
- 不支持公众号 AppID/AppSecret、回调 Token 或 `/wechat/callback`。
- 不承诺所有微信账号均可通过 Web 协议登录。
- 不规避微信风控，不提供多账号群控、营销或批量加好友功能。
- 不进行医学诊断，不替代心理治疗或紧急救援。

## 6. 核心流程

1. 管理员在后台添加个人微信渠道。
2. 系统创建 DRAFT 渠道，启动本地 Chromium 和 Wechaty。
3. 后台展示二维码；管理员用手机微信扫码并确认。
4. 登录成功后渠道自动进入 ACTIVE，消息处理默认开启。
5. 好友发送文本；系统幂等入库、安全分流、生成回复并发送。
6. 进程重启后使用本地会话自动恢复；失效时后台显示失败并要求重新扫码。

## 7. 验收标准

| ID | Given / When / Then |
| --- | --- |
| AC-WX-01 | Given 已登录后台，When 添加名称非空的微信个人号渠道，Then 创建 DRAFT 且不要求 AppID/AppSecret。 |
| AC-WX-02 | Given 渠道存在，When 点击扫码登录，Then 立即返回启动中状态，随后可轮询本地生成的二维码和登录状态。 |
| AC-WX-03 | Given 手机确认登录，When Wechaty 触发 login，Then 渠道变为 ACTIVE、显示昵称并启用消息处理。 |
| AC-WX-04 | Given 未登录，When 启用渠道，Then 返回 409 且提示先扫码登录。 |
| AC-WX-05 | Given 已登录且启用，When 好友发送文本私聊，Then 只生成一条入站记录、一条对话记录和一条回复。 |
| AC-WX-06 | Given 相同 messageId 重复到达，When 再次处理，Then 不重复调用模型或回复。 |
| AC-WX-07 | Given 群聊或非文本消息，When 到达，Then 不进入分析和对话表。 |
| AC-WX-08 | Given 管理员退出微信，When 操作成功，Then Bot 停止、渠道禁用、本地凭据删除。 |
| AC-WX-09 | Given Chromium 缺失，When 发起扫码，Then 返回可操作的错误且不泄露会话数据。 |
| AC-WX-10 | Given Wechaty 启动失败并在清理阶段再次超时，When 后台展示失败，Then 保留首个根错误且不显示无意义的 5 秒清理超时。 |
| AC-UI-01 | Given 任意后台页面，When 切换语言，Then 中英文立即切换并在刷新后保留。 |

## 8. 上线门禁

代码级门禁为类型检查、格式检查、自动化测试和生产构建全部通过。真实上线还必须在目标 Linux 主机使用专用微信号完成扫码、收消息、回复、重启恢复和退出登录验证。由于上游 Puppet 使用非官方协议和旧版浏览器自动化依赖，未完成风险接受前结论为 `NO-GO`。
