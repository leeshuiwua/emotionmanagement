# 观心镜管理后台 UI 规范

版本：V1.2（2026-09-13 视觉统一）

## 1. 页面任务

`/admin/wechat` 的单一任务是让管理员看清个人微信是否已登录、是否正在处理私聊，并能完成添加、扫码、启停和退出。

## 2. 视觉方向

采用安静、清晰的灰绿浅色管理台：背景 #f3f6f5、白色功能卡、墨绿正文 #203831、次级文字 #667b73、主操作 #237665、浅绿衬色 #e5f1eb。宋体仅用于品牌和页面标题，系统无衬线用于表单操作，等宽字用于金额或状态。移除浮动佛像装饰，减少大面积留白。统一主题位于 src/web/src/admin-ui.css，在各功能样式之后加载。

卡片圆角12–16px，控件圆角8px，操作按钮高38–42px。危险操作用低饱和红色，与主要操作分离。键盘焦点必须可见。

## 3. 微信页面

### 3.1 IM 渠道卡

渠道行展示：

- 渠道名称；
- 固定类型“微信个人号”；
- 登录微信昵称或“未登录”；
- 启动中/等待扫码/待手机确认/已登录/连接失败；
- “扫码登录”按钮；
- 已登录后可用的启停开关。

渠道卡片采用显式网格区域：第一行账号、连接状态、扫码与开关；操作栏独占整行，禁止落入图标宽度的列。所有操作按钮禁止逐字换行，长账号省略显示。添加入口置于卡片标题栏右侧，手机宽度下独占标题栏第二行。

无渠道时显示明确空状态。“添加渠道”始终可见。

### 3.2 添加渠道弹窗

- 渠道类型固定为“微信（个人号 · 扫码登录）”。
- 名称必填，默认“我的微信”。
- 说明文字明确手机扫码确认、登录凭据只保存在本机。
- 保存创建 DRAFT，不弹出公众号参数表单。

### 3.3 扫码弹窗

- STARTING：显示启动反馈。
- WAITING：显示 320px 二维码及手机扫码说明。
- SCANNED：提示在手机确认，不误报“已登录”。
- CONNECTED：绿色成功态并说明可收发好友私聊。
- EXPIRED/FAILED：显示具体错误和重新生成按钮。

### 3.4 本地会话舱

显示登录账号、会话凭据“本机文件·不上传”、消息范围“好友文本与语音私聊”（语音限 iLink 已转写内容）。黄色风险条必须常驻，说明个人微信没有官方机器人 API，并建议专用账号。退出微信是次级危险操作，执行前确认并说明会删除本地凭据。

## 4. 响应式与无障碍

- 980px 以下改为单列，会话轨道图置于说明上方。
- 620px 以下隐藏渠道启停开关，仍保留主要扫码动作；详情三列改为单列。
- 弹窗具备 `role=dialog`、`aria-modal`、可读标题和关闭标签。
- 所有按钮支持键盘焦点，遵守 `prefers-reduced-motion`。
- 中英文切换不改变信息结构。
